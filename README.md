# 🦅 EAGLE Panel — Railway MINI

همون پنل همیشگی — ولی این‌بار ریپو فقط **۳ آیتم** داره (مثل ریپوهای ۳-۴ فایلی Railway):

```
├── app.py        ← همه‌ی بک‌اند در «یک» فایل: API پنل + رله‌ی VLESS-WS + رله‌ی XHTTP + کارت اعتبار ریلوی
├── Dockerfile    ← دیپلوی (وابستگی‌ها داخل خودشه — بدون requirements.txt و start.sh)
├── README.md     ← همین راهنما
└── web/          ← کل ظاهر پنل (index.html + assets/app.css و app.js) — بدون pages.py!
```

> ❌ `pages.py` نیست — ظاهر پنل الان فایل‌های HTML/CSS/JS واقعی توی `web/` است، راحت ادیت می‌شه.
> ❌ `main.py` / `railway_api.py` / `relay_vless.py` / `xhttp_siz10.py` هم نیستند — همه ادغام شدند توی **یک** `app.py`.
> ✅ پنل مثل قبل واقعاً وصل می‌شه، پینگ می‌ده و ظاهرش همون قبله.

## 🚀 دیپلوی روی Railway (۳ قدم)

1. این ۳ آیتم رو توی یک ریپوی GitHub بذار
2. Railway → **New Project → Deploy from GitHub repo**
3. تمام! (اختیاری: یک **Volume** روی مسیر `/data` وصل کن تا کانفیگ‌ها بعد از ری‌استارت بمونن)

## 🔑 ورود پیش‌فرض

- نام کاربری: `admin` — رمز: `P443` (بعد از اولین ورود از داشبورد عوضش کن)

## 💵 کارت اعتبار ریلوی (۵ دلار)

از داشبورد → «تغییر توکن ریلوی»، توکن API رو از `railway.com/account/tokens` وارد کن.
داشبورد زنده نشون می‌ده: اعتبار باقی‌مانده، مصرف این سیکل، میانگین روزانه، خروجی شبکه و ایمیل حساب — مستقیم از API رسمی ریلوی، با کش ۶۰ ثانیه‌ای.

## 🛰️ پروتکل‌ها

VLESS-WS · VLESS-gRPC · VLESS-XHTTP (packet-up / stream-up) · VLESS-HTTP/2 · Trojan-WS · Shadowsocks
